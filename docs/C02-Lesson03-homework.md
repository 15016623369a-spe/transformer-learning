## 第一题：概念答案

| 问题 | 答案 |
|---|---|
| 一个头包含全部 Token 吗？ | 包含。等宽拆分分配的是特征维度，每个头仍覆盖全部位置。 |
| 一个 Linear 怎样容纳多个头的投影？ | 按输出特征分组，分别对应各头；每个输出特征都可以使用完整输入特征进行计算。 |
| 投影与拆头有何区别？ | Linear 通过可学习参数生成新特征；reshape、transpose 组织维度，没有可学习参数。 |
| 为什么除以 sqrt(head_dim)？ | 每个头的 Q/K 点积实际包含 head_dim 个特征，按这个维度缩放。 |
| 输出投影的作用？ | 对拼接后的各头特征做可学习组合，生成每个位置的最终 D 维输出。 |
| 第一个 Query 的权重为何不能体现头的区别？ | 因果限制下只有第一个 Key 被允许，归一化后必然得到 [1,0,…]，不能由此推断投影参数相同。 |

关于等宽拆分：本课与标准 nn.MultiheadAttention 均要求 D 可被 H 整除。自定义不等宽头需要分别实现投影、缩放与拼接。

## 第四题：错误案例及修正

### 案例 A：D=8、H=3

教师代码首先在配置检查处抛出 ValueError，因为 8%3≠0，无法按本课写法等宽拆头。仅令 head_dim=8//3=2 不能解决问题：3×2=6，无法容纳 8 个特征。

保留 D=8 时，可以改成 H=2，得到每头 4 维；需要三个等宽头时，应选择可被 3 整除的 D，并同步调整相关层。

### 案例 B：直接 reshape 合并

```python
toy = torch.arange(48).reshape(2, 3, 8)
heads = toy.reshape(2, 3, 2, 4).transpose(1, 2)
bad_restored = heads.reshape(2, 3, 8)
```

实际结果：形状相同=True，数值相同=False。原始第一行为 `[0,1,2,3,4,5,6,7]`，错误合并后为 `[0,1,2,3,8,9,10,11]`。

修正：

```python
restored = heads.transpose(1, 2).contiguous().view(2, 3, 8)
assert torch.equal(restored, toy)
```

先恢复 `[B,T,H,head_dim]`，再合并最后两个维度；本次修正后的数值完全相同。练习脚本的 `run_debug_exercises()` 已将预期错误与正确恢复明确区分，不会因预期错误中断后续演示。
